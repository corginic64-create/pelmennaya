# Пельмень — сайт кафе

Одностраничный сайт для кафе «Пельмень»: пельмени и вареники ручной лепки.
Сделан без фреймворков — только HTML, CSS и немного JavaScript.

**Живая версия:** https://corginic64-create.github.io/pelmennaya/

## Что внутри

- `index.html` — вся страница и текст
- `styles.css` — палитра, типографика, анимации, адаптив
- `script.js` — появление блоков при скролле и состояние шапки

## Как поменять содержимое

| Что | Где |
|---|---|
| Названия блюд и цены | `index.html`, блок `<section class="menu">` |
| Адрес и часы | `index.html`, блок `<section class="visit">` |
| Телефон | `index.html`, ссылки `tel:+79000000000` |
| Ссылка на ВК | `index.html`, класс `visit__vk` |
| Цвета | `styles.css`, переменные в `:root` |

## Локальный просмотр

Открыть `index.html` в браузере или запустить сервер:

```
python -m http.server 8000
```

и зайти на http://localhost:8000

## Публикация

GitHub Pages включён: изменения, отправленные в ветку `main`, автоматически
обновляют сайт в течение минуты.
